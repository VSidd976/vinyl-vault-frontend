# vinyl-vault-frontend

`vinyl-vault-frontend` is a frontend part of `vinyl-vault` project.

## Instalation

Use git to instal `vinyl-vault-frontend`.

```bash
git clone https://github.com/VSidd976/vinyl-vault-frontend.git
```

## Ports and adresses

* **Frontend URL**: `http://localhost:3000`
* **Backend URL**: `http://127.0.0.1:8000/api/v1`

## How to run

1. Make sure you're hosting backend on local machine on port `8000`.
2. Host server  within a frontend directory using port `3000`:

    ```python
    python -m http.server 3000
    ```

3. Open browser with your adress.
